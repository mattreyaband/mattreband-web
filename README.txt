Mattreya site - archivos para subir a GitHub y desplegar en Vercel.

Archivos:
- index.html
- styles.css
- script.js

Subida rápida en GitHub web:
1. Abre tu repositorio.
2. Add file -> Upload files.
3. Arrastra estos 3 archivos.
4. Commit changes.

Luego en Vercel:
1. Add New -> Project.
2. Import Git Repository.
3. Elige este repo.
4. Framework Preset: Other.
5. Build Command: dejar vacío.
6. Output Directory: dejar por defecto (.)
7. Deploy.
